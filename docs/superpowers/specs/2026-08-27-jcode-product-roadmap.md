# Jcode product roadmap

Date: 2026-08-27
Priority: compounding intelligence first

## North star

Jcode should make engineering work easier each time it is used.

## 1. Compound intelligence

Turn repeated success into reusable capability.

### Now

**Skill Crystallization**

- User asks Jcode to capture a repeated workflow.
- Jcode verifies examples from past sessions.
- Jcode proposes an exact global skill.
- Nothing is installed until the user approves it.
- Approved skills become immediately available.

Design: `docs/superpowers/specs/2026-08-27-skill-crystallization-design.md`

### Next

- Proactively suggest repeated workflows using the same proposal and approval path. On-demand discovery is implemented; the non-interruptive Learning Inbox is specified in `docs/superpowers/specs/2026-08-27-learning-inbox-design.md`.
- Create portable context capsules for handoffs.
- Compile smaller, better task context.
- Learn editable preferences and project invariants from evidence.

## 2. Trust autonomous work

Make “done” consistent and inspectable.

- Outcome contracts.
- Proof tied to requirements.
- Explicit autonomy levels.
- Reusable approval and verification gates.
- Replayable decisions and rollback points.
- Safe ambient project stewardship.

## 3. See and steer work

Make concurrent work understandable without reading every agent transcript.

- Mission Control.
- Attention Inbox.
- Native work-DAG navigation.
- Live diffs, tests, and evidence.
- Persistent multi-surface workspace.

## Rules

- Build one small end-to-end workflow at a time.
- Reuse sessions, todos, swarms, schedules, memory, and the shared server.
- Do not create parallel orchestration systems.
- Require evidence for learned behavior.
- Never install learned skills or widen autonomy without approval.
- Measure whether each feature reduces work or human attention.
